Middleware Pipeline
securityHeaders → cors → requestLogger → authenticate (JWT verify) → tenantContext (org_id) → rateLimiter (token bucket)

Validates body against schema validator · Calls appendEvent(shipmentId, orgId, event)
4
Event Log appends to PostgreSQL (TimescaleDB hypertable)

5
State Machine validates transition
e.g. in_transit → location_updated is valid · cancelled → location_updated throws (invalid transition)
6
Exception Detector runs automatically
Check 1: Is delivery >2h past estimated? · Check 2: Last update >45min ago? · Check 3: Location jumped >50km in <10min? (anomaly)
7
Spatial Index updated (R-tree)
Driver's new position entered into R-tree bounding box structure · Enables O(log n) "find all shipments near lat/lon" queries
8
WebSocket broadcasts to room "shipment:abc-123"
wsServer.broadcast(room, payload) → RoomManager finds all connections → each WsConnection.send() → RFC 6455 text frame written to TCP socket
9
Redis pub/sub fan-out (multi-node scale)
If multiple server instances are running, the event is published to Redis · All other nodes receive it and broadcast to their own connected clients

1
POST /api/v1/orders
Body: { customer_id, items: [{ sku, quantity }] } — passes auth + tenant middleware
2
order.service.ts queries warehouse inventory
Fetches all warehouses + inventory for org · Builds bipartite cost matrix: haversine distance + inventory deficit penalty (+1000/missing SKU) + capacity penalty (utilisation × 200 if >80%)

1
shipment.delivered event fires on EventBus

2

WebSocket — Built from Raw TCP

Zero library. The WebSocket server handles the RFC 6455 protocol from scratch: HTTP → TCP upgrade, handshake, frame parsing (masking, XOR decode, 64-bit payload length), ping/pong heartbeat, graceful close frames, Redis pub/sub for multi-node scale. No ws npm package.
core/ws/server.ts
  • Listens for HTTP "upgrade" events
  • Validates Sec-WebSocket-Key header
  • Sends 101 Switching Protocols response
  • Creates WsConnection per upgrade
  • Starts 30s ping heartbeat per connection
  • Drops unresponsive connections
  • Subscribes to Redis for multi-node events
core/ws/connection.ts
  • Accumulates TCP data into buffer
  • Parses RFC 6455 frames (while loop)
  • Handles 126 / 127 extended payload length
  • XOR-unmasks client-to-server frames
  • Dispatches text / binary / ping / pong / close opcodes
  • Builds server frames (FIN=1, never masked)
  • Emits pong event (heartbeat tracks liveness)
core/ws/rooms.ts
  • Map(roomId → Set of WsConnections)
  • join(conn, room) / leave(conn, room)
  • broadcast(room, message) to all in room
  • Cleans up on connection close
  • Room names: "shipment:uuid", "org:uuid"
